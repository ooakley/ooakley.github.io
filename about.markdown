Hey! I'm Omar El Oakley, a PhD student at the Francis Crick Institute in London. I'm working on how to use machine learning to understand viruses better - I'll be using this place to put all the interesting things I come across during my research, plus any and all of the other things which I hope you might find interesting.

Specifically, I'm working in the [Cell Biology of Infection Lab](https://www.crick.ac.uk/research/labs/rupert-beale) where I'm using some cool new deep learning techniques to analyse how viruses (we use Influenza A) hijack the cell's recycling machinery. The deep learning techniques are useful because they can (in theory) tease apart how patterns in this machinery change when cells are infected.
